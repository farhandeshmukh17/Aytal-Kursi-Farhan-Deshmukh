# Ayat-ul-Kursi (آيَةُ الْكُرْسِيِّ)

An elegant, mobile-responsive web application designed to present Ayat-ul-Kursi (Surah Al-Baqarah 2:255) in structured visual sections.

## Features
* 📖 **Arabic Text, Transliteration & English Translation** broken down section-by-section.
* 🎧 **Audio Recitation** by Sheikh Mishary Rashid Alafasy with playback control and synchronized slide transitions.
* 🌌 **Interactive UI** featuring responsive starry night animations and clean navigation.
* 📱 **Fully Responsive** optimized for desktop, tablet, and mobile displays.
